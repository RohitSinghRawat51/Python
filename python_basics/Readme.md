Python was developed by Guido Van Rosum in 1991

Python is a general purpose programming language - versatality

Python comments are text written within a program to undestand the program

Keywords->they are reserved word whose meaning is already known to the interpreter

Variable-> container to store any value. eg- a=5, where a is variable which hold integer value 5
Rules for creating variables
->We can use a-z,A-Z, 0-9,_
->We cannot start any variable with number
->We cannot use space in our variable
->We shouldn't use keywords as our variables
->Other than _ no other special symbol can be used

Python is a dynamically typed language - we don't need to explicitly assign the data type of variable
